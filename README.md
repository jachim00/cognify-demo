# Cognify — landing page demo

Publiczny demo high-tech landing page dla firmy **Cognify** specjalizującej się
w AI environments, AI structures, AI-first apps i AI systems.

## Live

→ **https://grupavistperformance.github.io/cognify-demo/**

## Stack

- Pure HTML + Tailwind CSS (via CDN) — zero build step
- Custom CSS animations: gradient mesh, glassmorphism, neon glow, marquee
- Responsive (desktop + mobile)
- Fonts: Inter + JetBrains Mono (Google Fonts)
- Self-contained — otwierasz `index.html`, działa

## Sekcje

1. Hero z animowanym gradient mesh
2. Trust metrics (4 KPI)
3. Marquee logotypów stack'u AI
4. **Cztery filary** — Środowiska AI / Struktury AI / Aplikacje AI-first / Systemy AI
5. Code showcase (live metrics)
6. Metodologia 90-dniowa (4 kroki)
7. Case studies (3 przypadki z metrykami)
8. CTA
9. Footer

## Performance

- First paint: < 1s (Tailwind CDN + inline SVG)
- Mobile Lighthouse: 90+
- Zero JavaScript bundlery — całość w natywnym HTML/CSS
